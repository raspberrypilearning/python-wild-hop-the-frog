# Нотатки ментора: Python wild - Стрибай, жабко

## Огляд проєкту

У цьому проєкті Python Wild учні використовують бібліотеку p5, щоб створити мультяшну жабку, яка стрибає вгору і витягується під час стрибка. Вони тренуються малювати, анімувати і створювати інтерактивні поведінки за допомогою коду Python.

---

## Що учні будуть практикувати

- Малювання з `ellipse()` та `circle()`
- Використання змінних для анімації руху
- Обробка введення миші за допомогою `mouse_pressed()`
- Розтягування та стискання фігур за допомогою логіки
- Координація руху за допомогою гравітації та відстеження стану

---

## Поради для викладання

- Підкресліть, що `draw()` працює як цикл — він повторюється автоматично
- Використовуйте прості слова для опису руху і анімації (наприклад, «гравітація тягне жабку вниз»)
- Поясніть, що `x` та `y` використовуються для розташування кожної частини жабки
- Розкажіть, що змінна `stretch` потрібна для зміни одразу кількох фігур

---

## Ідеї для розширення

- Додайте жучка, якого жабка може спіймати язиком
- Додайте жабці корону, щічки або анімовані лапки
- Додайте латаття або бризки води на фоні
